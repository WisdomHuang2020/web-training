M08云服务器选购（腾讯云轻量）

所属路径 Q / A / B / C 第 8 / 32 讲 S2 买与备
在腾讯云轻量买什么规格、怎么留后路
学完能独立买一台轻量服务器，并把它变成随时可回滚的状态

01为什么重要

买机器是一次性动作，但「能不能回到买来时的状态」决定了你后面敢不敢动手。快照不是备份策略，是操作许可证。

02要讲清的 4 件事核心要点

  • 只讲腾讯云轻量应用服务器，不横向对比其他厂商（避免截图与口径分叉）
  • 规格起步 2C2G；带宽按峰值或按流量两种计费；地域影响备案接入
  • 买完先做两件事：记录实例 ID 与公网 IP，打一张初始快照
  • 先配自动快照策略，再看到期与续费提醒

03照着做：4 步操作顺序

  1. 选地域与规格（2C2G 起步）
  2. 买完立刻记录实例 ID 与公网 IP
  3. 打一张初始快照再动任何配置
  4. 打开自动快照策略与到期提醒
ssh -i ~/.ssh/你的密钥 root@服务器IP "hostname; df -h; free -m"

04产出物与验收做完怎么算过

产出物

一台可登录机器 + 一张可用快照

验收判据

可验SSH 能进；能从当前状态回滚到初始快照

05练习15 分钟内可做完

故意改坏一个配置，再从快照恢复，记录恢复耗时。

06最容易踩的坑

只买机器不留快照；机器到期下线前没做迁移
后果：配置改坏又没有快照，只能重装系统，前面所有环境配置白做一遍。

08本讲术语全部 106 条

  • A 记录 / CNAME：A 记录把域名指到一个 IP；CNAME 把域名指到另一个域名，由后者再解析。
  • 云服务器 / VPS：云厂商把一台物理机切成多台虚拟机出租，你租的那台有独立的 CPU / 内存 / 磁盘 / IP。
  • ICP 备案：在中国境内提供互联网信息服务的行政许可：在工信部系统登记主办者信息、取得备案号。
  • 实例（Instance）：云控制台上「一台机器」的正式叫法。买服务器＝创建实例，账单、规格、重装都按实例算。
  • 服务器快照：云平台给整台机器磁盘存的一个还原点。改配置前先打一张，坏了一键回滚。
  • 回滚：把线上退回上一个可用版本。能做回滚的前提是：每次发布都留了可回退的版本点。
