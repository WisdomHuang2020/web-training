M16HTTPS 与证书

所属路径 Q / A / B / C 第 16 / 32 讲 S3 上线
免费证书 + 自动续期
学完能让一个域名稳定跑在 https 上，并知道它什么时候过期

01为什么重要

证书不是装上就完事，它会过期。免费证书 90 天一轮，如果续期静默失败，某天会全站一起告警——而那天往往是你最不想处理它的日子。

02要讲清的 3 件事核心要点

  • 免费 DV 证书；DNS-01 与 HTTP-01 的区别
  • 自动续期与到期监控
  • 强制 301 到 https；HSTS 的副作用

03照着做：4 步操作顺序

  1. 为域名申请 DV 证书
  2. 配 443 server 块并指向证书
  3. 加 301 强制跳转到 https
  4. 设证书到期监控，别等它自己过期
echo | openssl s_client -servername 你的域名 -connect 你的域名:443 2>/dev/null | openssl x509 -noout -dates
curl -I https://你的域名 | head -1

04产出物与验收做完怎么算过

产出物

全站 https

验收判据

可验curl -I 返回 200 且证书剩余超过 30 天；http 自动跳 https

05练习15 分钟内可做完

用 --resolve 直连 IP 访问，分辨问题是 DNS 还是证书。

06最容易踩的坑

续期静默失败，某天全站一起告警
后果：用 HTTP-01 验证，但域名还没解析生效——签发必然失败，而你只能看到一句模糊的错误。
