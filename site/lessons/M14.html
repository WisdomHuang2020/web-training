M14服务器环境与目录规划

所属路径 A / B / C 第 14 / 31 讲 S3 上线
多站共存的目录与属主
学完能在一台已有多个站的服务器上安全地新增一个站

01为什么重要

nginx 以 www-data 身份读文件。文件属主是 root、权限又收紧时，nginx 读不到，返回 403，而错误日志只写 permission denied，不会告诉你是属主问题。

02要讲清的 4 件事核心要点

  • nginx 安装与 /var/www/站点 目录规划
  • 属主归 nginx 运行用户
  • sites-available / sites-enabled；日志路径与切分
  • 站点清单以服务器 sites-enabled 现值为准，不照抄任何文档

03照着做：4 步操作顺序

  1. 建 /var/www/站点 目录
  2. 属主改成 nginx 运行用户
  3. 写 sites-available 并 enable 软链
  4. nginx -t 通过后再 reload
sudo mkdir -p /var/www/site
sudo chown -R www-data:www-data /var/www/site
sudo nginx -t && sudo systemctl reload nginx
namei -l /var/www/site/index.html   # 逐级看权限

04产出物与验收做完怎么算过

产出物

目录结构 + 一份当前站点清单

验收判据

可验nginx -t 通过；新站上线后老站状态码不变

05练习15 分钟内可做完

在不动其他站的前提下加一个只有一页的站，再删掉，确认老站无变化。

06最容易踩的坑

属主没归位直接 403；顺手改了别的站目录
后果：为了省事全目录 777，安全上等于不设防，网站内容谁都能改。
